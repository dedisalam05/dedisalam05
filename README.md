### 🎯 5 Pilar Tugas Utama
1. **Distributed System Topology & Service Boundary:** Memetakan topologi layanan (API Gateway, User Service, Notification Service, Auth) dan mengisolasi domain data secara mandiri.
2. **Event Choreography & AMQP Broker Design:** Menstandarisasi schema pesan RabbitMQ (exchanges, routing keys, queues) dan Redis pub/sub untuk zero-loss inter-service communication.
3. **Database Schema & Index Architecture:** Merancang skema Mongoose/MongoDB dengan prinsip *Zero-COLLSCAN* (seluruh query terindeks majemuk dengan latensi p95 < 50ms).
4. **Hexagonal Architecture (Ports & Adapters):** Menjamin isolasi penuh antara inti domain bisnis (*Core Domain*) dengan protokol eksternal (HTTP, WebSocket, RPC, Database drivers).
5. **Architectural Decision Records (ADR):** Mendokumentasikan dan memelihara seluruh keputusan struktural sistem dalam format *Architecture-as-Code*.
